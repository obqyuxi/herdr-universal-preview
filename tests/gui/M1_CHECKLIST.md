# M1 人工 GUI 验收清单（Herdr Preview Dev，隔离环境）

**准备（由 Agent 执行）**：`scripts/dev app-up`，然后在窗口里切换到 `universal-preview` 布局。窗口左边是测试终端（测试 core，与正式 Herdr 无关），右边上下两个预览面板：上面默认是"站点(交互)"，下面默认是"PDF"。每个面板顶部的按钮用来切换样例，第二行按钮用来操作当前视图。

**只操作标题为 Herdr Preview Dev 的窗口。** 每一项请回复"通过 / 不通过 + 看到了什么"。不方便测的项可以跳过，会如实记为"未测"。

| # | 操作 | 预期现象 |
|---|---|---|
| G1 | 看右侧两个面板 | 上面面板直接显示网页（蓝色标题"本地测试页"、棋盘图片），下面面板显示 PDF 第 1 页。两者都在 Herdr 窗口内部，不是单独的窗口 |
| G2 | 上面网页：点"点我计数"几次 | 右边的数字增加 |
| G3 | 点网页里的输入框，用拼音输入法打"中文测试" | 候选框出现在输入框附近，能选字；右边回显"→ 中文测试" |
| G4 | 在网页里选中一段文字，按 ⌘C；点左边终端，按 ⌘V | 终端里出现刚才复制的文字 |
| G5 | 在终端里输入 `sleep 100` 回车，再按 Ctrl+C | sleep 被中断（Ctrl+C 没有被网页拦截） |
| G6 | 点网页里的"站内链接：第二页"，在第二页上滚动；然后点面板上的"后退" | 进入第二页，可以滚动，"后退"后回到首页 |
| G7 | 点"新窗口链接" | 在同一个面板内打开第二页，不会弹出新窗口 |
| G8 | 面板顶部点"站点(静态)" | 页面显示"脚本未运行（静态模式…）"，"点我计数"按钮无效 |
| G9 | 点"example.com" | 显示 example.com 网页，点击页面上的链接可以跳转 |
| G10 | 下面 PDF：滚轮滚到第 2、3 页；点"第2页""放大""适应宽度" | 能看到后续页面，跳页和缩放生效 |
| G11 | 在 PDF 里拖选一段中文，按 ⌘C，粘贴到终端 | 粘贴出 PDF 里的中文文字 |
| G12 | 下面面板点"MP4"，再点视频控制条上的播放（或第二行的"播放"） | 画面开始动（背景颜色和方块数量随秒变化），**能听到持续的音调**；拖动进度条到后半段，画面相应跳过去；暂停后声音停止 |
| G13 | 点"MOV"，重复 G12 | 同 G12 |
| G14 | 依次点"MP3""WAV""M4A"并播放 | 每个都能听到一句中英文合成语音；进度条和音量可调 |
| G15 | 播放中点另一个样例（例如"PDF"） | 声音立刻停止 |
| G16 | 点"DOCX"，滚动 | 显示 Word 内容（中文标题、表格），能滚到第 2、3 页 |
| G17 | 点"XLSX" | 显示表格内容；能切换或看到 3 个工作表（如果做不到，请说明你看到了什么） |
| G18 | 点"PPTX" | 显示幻灯片，能看到第 2 张及之后的幻灯片 |
| G19 | 按 ⌘⇧P 打开命令面板 | 命令面板完整显示在预览区域上方，可以点击、可以输入；预览区暂时变成灰色提示文字"…被 Herdr 菜单/对话框暂时遮挡"。按 Esc 关闭后，网页或 PDF 回到原来的位置和状态（PDF 仍在原来那一页） |
| G20 | 拖动右侧两个面板之间的分隔线，以及左右两栏之间的分隔线 | 原生视图跟着改变大小，不会盖到别的区域，也不错位 |
| G21 | 拉大、缩小整个窗口；最小化后再恢复 | 视图跟着窗口变化；恢复后内容还在 |
| G22 | 点"隐藏视图"，再点"显示视图"；点"关闭视图"，再点"重新打开" | 隐藏后能看到下面的提示文字，显示后状态还在；关闭后视图消失（播放中的媒体声音停止），重新打开会重新加载 |
| G23 | 在网页里点一下，再点终端打字 | 字符出现在终端里，不会出现在网页里 |
| G24 | 两个面板同时显示不同内容（例如上面网页、下面视频） | 两个视图同时正常显示，互不干扰 |

每项结果会连同 `native.debug` 的自检 JSON 一起写入 `docs/ACCEPTANCE.md`。
